# UMW-GBUS-562
Repository for GBUS 562 (AI Language Models) 

## About
This repository holds materials created for the University of Mary Washington's GBUS 562 course, AI Language Models. Content is organized into weekly folders.

## Weekly Work
1. week-01
   - [Connect Four](week-01/connect-four.html): A single-page browser game of Connect Four. Play against a computer opponent with three difficulty levels (Easy, Medium, Hard), or switch to two-player mode to take turns with a friend on the same device.
2. week-02
   - [Prompt Lab](week-02/prompt-lab.html): A web app for testing prompts against Claude, built with Claude Code.
